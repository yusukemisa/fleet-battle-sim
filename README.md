# 艦隊決戦

俯瞰の戦場で、青軍と赤軍が陣形を保ったまま撃ち合うシミュレーターです。艦は色のついた四角です。固有の人名、艦名、紋章は使いません。

## 起動する

Node.js 22 以降を使います。

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:43173/ を開きます。

`npm test` でシミュレーションのテスト、`npm run lint` で型検査と lint が走ります。

## 操作する

初期の隻数は 1,000 です。上の「隻数」から 100、1,000、10,000 を選べます。開戦前だけ変更できます。

両軍の初期陣形は鶴翼です。陣形の選択も開戦前だけです。

1. 青軍と赤軍の陣形を選ぶ。
2. 各軍の指揮官を選ぶ。初期値は常勝です。手動にすると、戦術は自動で変わりません。
3. 「開戦」を押す。
4. 戦闘中も「分艦隊の戦術」から、分艦隊ごと、または全軍に戦術を出せます。指揮官が自動のときは、状況が変わると戦術を切り替え、左上に「赤軍 左翼: 包囲に切替」のように出します。
5. 速度は ×1、×2、×4。Space で停止と再開。
6. ドラッグで移動、ホイールで拡大。「全体」で全軍が見える位置に戻る。

左下の凡例は、その時点の残存数と陣形名です。

## 陣形を足す

陣形は `src/formations.ts` の `FORMATIONS` に 1 件足します。`src/types.ts` の `FORMATION_IDS` にも同じ id を足します。ここを足さないと型が通りません。

`place` は艦隊のローカル座標を書き込みます。+Y が敵の方向です。関数の最後で重心を原点に戻し、左右の分艦隊へ船を振り分けます。方円だけは中心の中軍を自分で割り当てます。

## 戦術を足す

戦術は `src/tactics.ts` の `TACTICS` に 1 件足します。`TACTIC_IDS` にも同じ id を足します。`step` がその分艦隊の錨を動かします。新しい移動の種類が要るときだけ、共有の `steer` 以外の処理を足します。

## 指揮官を足す

指揮官は `src/commanders.ts` の `COMMANDERS` に 1 件足します。`COMMANDER_IDS` にも同じ id を足します。`base` は戦術ごとの重み、`rules` はその状況で足す重みです。`chooseTactic` が最大の戦術を返します。手動は `auto: false` で、戦術を変えません。

## 艦の性能

全部の艦が同じ性能です。数値は `src/balance.ts` の `SHIP_STATS` にまとめてあります。体力、ダメージ、射程、旋回速度、前方射角、装甲の倍率もここです。艦は艦首の方向へ進み、真横には滑りません。射撃は艦首の扇の中だけです。正面の被弾は軽く、背面は重くなります。

艦種を足すときは、このオブジェクトを艦種ごとの表にします。戦闘は `SimState.stats` を読むので、艦の列に艦種 id を足して表を引く形に替えられます。今は艦種を分けていません。

画面上の配置やビームの本数は `FIELD` です。艦の性能ではありません。

## 測定したフレーム時間

この環境は CPU 4 コアで、GPU デバイスはありません。ヘッドレス Chrome で、開戦 1.5 秒後から 2 秒を 5 回測りました。隻数の順は 100、1,000、10,000 を交互に繰り返しています。ページエラーはありません。各回で艦は減っていたので、射撃は動いています。

艦首への旋回を足したあとも、フレームの供給は毎秒 60 回で頭打ちでした。1 万隻の計算と描画は中央値 4.4 ms です。60 fps の枠は 16.7 ms なので、枠の側が上限です。計測は 5 周で、隻数の順は 100、1,000、10,000 です。ページエラーはなく、各回で艦は減っていました。

| 隻数 | フレーム数 | 計算と描画の中央値 | 最小から最大 | 計算 | 描画 |
| --- | --- | --- | --- | --- | --- |
| 100 | 600 | 0.2 ms | 0.0 から 0.4 ms | 0.0 ms | 0.1 ms |
| 1,000 | 600 | 0.6 ms | 0.4 から 1.2 ms | 0.2 ms | 0.3 ms |
| 10,000 | 597 | 4.4 ms | 4.0 から 13.6 ms | 2.1 ms | 2.3 ms |

100 隻の 0.2 ms はタイマーの分解能に近い値です。1 万隻では計算 2.1 ms、描画 2.3 ms です。呼び出し単位のプロファイルは取っていません。この環境に GPU デバイスはありません。
