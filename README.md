# 艦隊決戦

俯瞰の戦場で、青軍と赤軍が陣形を保ったまま撃ち合うシミュレーターです。艦は艦首の方向に長い長方形で、先端に艦首の印が付きます。固有の人名、艦名、紋章は使いません。

## 起動する

Node.js 22 以降を使います。

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:43173/ を開きます。

`npm test` でシミュレーションのテスト、`npm run lint` で型検査と lint が走ります。

公開版は https://yusukemisa.github.io/fleet-battle-sim/ です。`main` への push で GitHub Actions がテストとビルドを行い、`dist` を GitHub Pages に置きます。初回だけ、リポジトリの Settings → Pages → Build and deployment → Source を **GitHub Actions** にしてください。この設定はワークフローからは変えられません。

## 操作する

初期の隻数は 1,000 です。上の「隻数」は、両軍 1 艦隊ずつの均等な戦いに戻す近道です。100、1,000、10,000、20,000 から選べます。開戦前だけ変更できます。複数艦隊にしているときは「個別」と出ます。

両軍の初期陣形は横陣です。五つの分艦隊が横一列に並び、各隊は塊です。鶴翼やそれ以外の陣形も、開戦前に選べます。

1. 青軍と赤軍の陣形を選ぶ。
2. 各軍の指揮官を選ぶ。初期値は常勝です。手動にすると、戦術は自動で変わりません。「艦隊」で片側を 1〜3 艦隊にできる。数は揃わなくてよい。各艦隊の隻数は「分艦隊の艦種と戦術」の見出しで、50 から 10,000 まで 50 刻みのスライダーか数値で決める。100、500、1,000、2,000、5,000、10,000 のボタンもある。画面上に青・赤・合計と上限が出る。戦闘全体の上限は 2 万隻で、超える指定は黙って削らない。スライダーは要求した数のまま残り、各艦隊を同じ割合で上限まで縮めた配置数と、その旨を出す。陣形と指揮官も同じ見出しで選ぶ。隊名をクリックして選び、地図を押してドラッグすると、その地点へ着いてから矢印の向きを取る移動を命じます。短いクリックは進行方向を向きます。Shift で複数の隊をまとめて動かせます。右クリックか Esc で命令を消します。隊を選んでいないときのドラッグは、今までどおり地図を動かします。
3. 「開戦」を押す。
4. 戦闘中も「分艦隊の戦術」から、分艦隊ごと、または全軍に戦術を出せます。指揮官が自動のときは、状況が変わると戦術を切り替え、左上に「赤軍 左翼: 包囲に切替」のように出します。
5. 速度は ×1、×2、×4。×1 は実時間の半分で進み、戦闘の動きを追いやすい。×2 と ×4 はそれより速い。射撃間隔はシミュレーター時間の 2 秒のまま。Space で停止と再開。
6. ドラッグで移動、ホイールで拡大。「全体」で全軍が見える位置に戻る。

左下の凡例は、その時点の残存数と陣形名です。

艦隊同士が近づくと、多くの戦術は止まらず、上空から見て時計回りに回り続けます。距離と回る向きは `src/balance.ts` の `SWEEP` です。定点射撃、集中砲火、釘付けはこれには乗らず、艦首を敵へ向けたまま動きます。側面攻撃と背後襲撃も乗らず、智将の翼が敵の側面と背面へ回る動きを続けます。守将は定点射撃を選ぶので、その場から動きません。

智将は中軍を敵の正面に残し、左衛と右衛を側面へ、左翼と右翼を背面へ送ります。回り込みは敵の艦首射程の外を通り、射界から外れてから入ります。敵の射程の中では、艦首を脅威に向けたままにして、側面や背面を向く回頭は避けます。敵の分艦隊がこちらに背を向けているときは、中軍以外もそこへ向かいます。

## 陣形を足す

陣形は `src/formations.ts` の `FORMATIONS` に 1 件足します。`src/types.ts` の `FORMATION_IDS` にも同じ id を足します。ここを足さないと型が通りません。

`place` は艦隊のローカル座標を書き込みます。+Y が敵の方向です。関数の最後で重心を原点に戻し、左右の分艦隊へ船を振り分けます。方円だけは中心の中軍を自分で割り当てます。

## 戦術を足す

戦術は `src/tactics.ts` の `TACTICS` に 1 件足します。`TACTIC_IDS` にも同じ id を足します。`step` がその分艦隊の錨を動かします。新しい移動の種類が要るときだけ、共有の `steer` 以外の処理を足します。`sweep` を false にすると、接近しても艦隊の時計回りには乗りません。

## 指揮官を足す

指揮官は `src/commanders.ts` の `COMMANDERS` に 1 件足します。`COMMANDER_IDS` にも同じ id を足します。`base` は戦術ごとの重み、`rules` はその状況で足す重みです。`chooseTactic` が最大の戦術を返します。手動は `auto: false` で、戦術を変えません。

## 艦の性能

戦艦が基準です。巡航艦と駆逐艦は `src/balance.ts` の `CLASS_MODS` で、その倍率から作ります。一つの分艦隊は同じ艦種です。初期の並びは、両翼が駆逐艦、その内側が巡航艦、中軍が戦艦です。開戦前に「分艦隊の艦種と戦術」から隊ごとに変えられます。

艦は艦首の方向へ進み、真横には滑りません。正面の被弾は軽く、背面は重くなります。背面に砲はありません。装甲の数値は被弾倍率で、大きいほど多く削れます。船体が閉じて重なると、味方でも敵でも両方とも沈みます。質量は船体半径の二乗で、戦艦 50.4、巡航艦 17.6、駆逐艦 5.3 です。重い方が軽い方の 3 倍以上なら、軽い方だけが沈みます。同じ艦種や、戦艦と巡航艦は両方沈み、駆逐艦が巡航艦や戦艦に当たったときは駆逐艦だけが沈みます。閉じる速さが毎秒 64 未満の接触は押し分けて、どちらも残ります。1 ステップで沈める衝突は 48 組までです。被弾の白い線は艦の印で、艦そのものは軍の色のまま描きます。隻数の多い艦隊は、敵の前線が艦首砲の届く距離に入るとそれ以上近づかず、艦首を向けたまま撃ち合う。それより内側へ入った艦は下がる。方円のような小さい艦隊は、これまでどおり近づく。砲の間隔はどの艦種も基準 4.0 秒、斉射ごとに ±10% です。斉射の威力は門数 × 1 門あたりの威力です。外れた弾は、着弾点の近くに艦がいるほど、別の艦（味方でも敵でも）に当たることがあります。船体を貫いて撃沈した弾の残りも、その先の艦に届くことがあります。撃沈した艦は爆発し、船体が大きいほど広く、強く、隣の艦を削ります。戦艦の爆発が最も大きいです。

## 旗艦

各艦隊に旗艦が一人、各分艦隊に分艦隊旗艦が一人いる。艦隊旗艦は戦艦で、指揮半径は 640。分艦隊旗艦の半径は 300 で、その隊の戦艦、いなければ巡航艦、それもいなければ残っている艦から選ぶ。半径の中にいる艦は命中、発射間隔、被弾、旋回が少し良くなる。両方の半径に入っても、ボーナスは足し算の全部にはならない。

旗艦が沈むと、その指揮は一度切れる。ボーナスは消え、しばらく加速と旋回が鈍る。分艦隊旗艦は 8 秒後に同じ隊の次の戦艦か巡航艦へ移る。艦隊旗艦は 12 秒後に、まだ残っている分艦隊旗艦へ移る。画面では旗艦に輪が付き、艦隊旗艦の指揮半径は薄い円で出る。

ルールの指揮官は、自軍の艦隊旗艦を載せた戦艦隊を戦列に残す。敵の艦隊旗艦が翼に出ているか、その隊が薄くなっているときは、そこを獲物にする。学習する指揮官は、各隊の特徴に旗艦の有無を入れている。

| 戦艦 | 54 | 0.50 / 1.00 / 1.50 | 60 | 73 | 0.90 | 67 | 8 門 × 1.40、280–900、±40° | 16 門 × 0.50、0–420、±50° |
| 巡航艦 | 35 | 0.60 / 1.20 / 1.80 | 93 | 189 | 2.12 | 44 | 6 門 × 1.19、241–774、±40° | 12 門 × 0.425、0–378、±50° |
| 駆逐艦 | 18 | 0.725 / 1.45 / 2.175 | 144 | 510 | 4.14 | 35 | 4 門 × 0.77、146–468、±32° | 12 門 × 0.55、0–344、±58° |

戦艦の斉射は艦首 11.2、舷側 8.0 です。巡航艦は 7.14 と 5.10、駆逐艦は 3.08 と 6.60 です。駆逐艦は舷側の方が重く、戦艦は艦首の方が届きます。画面では戦艦が太く、巡航艦が細く、駆逐艦がさらに細い線です。

速力は毎秒の移動、加速は毎秒ごとの速度の増え、旋回は毎秒のラジアンです。旋回半径は最高速のまま回ったときの円です。戦艦は加速も回頭の立ち上がりも鈍く、駆逐艦はすぐ最高速に乗って小さく回ります。隊列を保って進むときは、速い艦も戦艦の歩調に合わせます。側面へ出る機動と、手動の移動命令では、その艦種の速力を使います。自動の指揮官は、戦艦を戦列に残して艦首砲で抑えます。駆逐艦は敵戦艦の艦首が届かない距離まで潜るか、味方戦艦の前で敵の駆逐艦を迎え撃ちます。猛将は早く突っ込み、智将は射界の外から合わせて潜り、守将は迎え撃つことを優先し、常勝は敵の迎えが外れたときだけ潜ります。

遠い相手には艦首を向け、近い相手には舷側を向けます。駆逐艦の分艦隊は戦列の外側に開き、戦艦は中軍に残ります。駆逐艦は最初の被弾で列を抜けると翼が崩れるので、退避で下がるのは戦艦と巡航艦です。

画面上の配置やビームの本数は `FIELD` です。艦の性能ではありません。

## 陣の広がり

分艦隊は左翼・左衛・中軍・右衛・右翼の五つのままです。戦術がこの五隊を指すため、隊の数は増やしません。隊の艦数は艦隊の隻数を五等分し、各隊の塊と陣の幅・奥行きは艦数が増えても隣の艦が重ならない間隔を保つように広がります。500 隻の艦隊は間隔 22 のままです。それより大きい艦隊は隻数の平方根に比例して間隔を開き、翼を伸ばします。5,000 隻の横陣は、500 隻のときより細い線にはなりません。

同じ側の艦隊は、それぞれの横幅の半分と 160 の空きを足した位置に置きます。5,000 隻の隣に 500 隻を置いても、足元は重なりません。艦首が戦場の中央を越える陣は、中央から 240 空くところまで後ろへ下げます。戦闘中に味方同士がそれより近づくと、押し戻します。

## 測定したフレーム時間

この環境は CPU 4 コアの Xeon で、GPU デバイスはありません。ヘッドレス Chrome、1440×900 で、開戦 1.5 秒後から 2 秒を 2 回測りました。ページエラーはありません。60fps の枠は 16.7 ms です。1 万隻を超えるとビームを間引きます。1 万隻は 2 本に 1 本、1.6 万隻は 3 本に 1 本です。

| 編成 | 達成 fps | 計算と描画の中央値 | 95% | 最大 | 計算 | 描画 |
| --- | --- | --- | --- | --- | --- | --- |
| 10,000（1 対 1） | 60 | 4.0 ms | 5.7 ms | 7.9 ms | 2.6 ms | 1.5 ms |
| 10,000（2,000+2,000+1,000 が両軍） | 60 | 4.4 ms | 4.9 ms | 5.7 ms | 2.5 ms | 2.0 ms |
| 12,000（2,000×3 対 2,000×3） | 59 | 5.0 ms | 6.4 ms | 18.8 ms | 2.9 ms | 2.2 ms |
| 15,000（2,500×3 対 2,500×3） | 60 | 6.2 ms | 7.5 ms | 10.4 ms | 3.6 ms | 2.6 ms |
| 20,000（5,000×2 対 5,000×2） | 60 | 7.8 ms | 8.3 ms | 10.7 ms | 4.6 ms | 3.2 ms |
| 20,000（10,000 対 10,000） | 60 | 8.1 ms | 9.4 ms | 12.6 ms | 5.3 ms | 2.8 ms |
| 30,000（5,000×3 対 5,000×3） | 56 | 12.0 ms | 12.4 ms | 14.3 ms | 7.0 ms | 4.9 ms |

上限は **2 万隻** です。2 万隻は中央値 8 ms で 60fps に収まり、最大でも 12.6 ms でした。3 万隻は 56fps まで落ちたので、これより遅いノートパソコンでは枠を割ります。12,000 隻の 18.8 ms は 1 フレームだけの飛びです。計算だけのステップ中央値は、10,000 が 3.6 ms、12,000 が 4.4 ms、15,000 が 5.2 ms、20,000 が 6.2〜10.1 ms、30,000 が 10.4 ms でした。
