# 艦隊決戦

俯瞰の戦場で、青軍と赤軍が陣形を保ったまま撃ち合うシミュレーターです。艦は艦首の方向に長い長方形で、先端に艦首の印が付きます。固有の人名、艦名、紋章は使いません。

## 起動する

Node.js 22 以降を使います。

```bash
npm install
npm run dev
```

ブラウザで http://127.0.0.1:43173/ を開きます。

`npm test` でシミュレーションのテスト、`npm run lint` で型検査と lint が走ります。

## 操作する

初期の隻数は 1,000 です。上の「隻数」から 100、1,000、10,000 を選べます。開戦前だけ変更できます。

両軍の初期陣形は横陣です。五つの分艦隊が横一列に並び、各隊は塊です。鶴翼やそれ以外の陣形も、開戦前に選べます。

1. 青軍と赤軍の陣形を選ぶ。
2. 各軍の指揮官を選ぶ。初期値は常勝です。手動にすると、戦術は自動で変わりません。
3. 「開戦」を押す。
4. 戦闘中も「分艦隊の戦術」から、分艦隊ごと、または全軍に戦術を出せます。指揮官が自動のときは、状況が変わると戦術を切り替え、左上に「赤軍 左翼: 包囲に切替」のように出します。
5. 速度は ×1、×2、×4。×1 は実時間の半分で進み、戦闘の動きを追いやすい。×2 と ×4 はそれより速い。射撃間隔はシミュレーター時間の 2 秒のまま。Space で停止と再開。
6. ドラッグで移動、ホイールで拡大。「全体」で全軍が見える位置に戻る。

左下の凡例は、その時点の残存数と陣形名です。

艦隊同士が近づくと、多くの戦術は止まらず、上空から見て時計回りに回り続けます。距離と回る向きは `src/balance.ts` の `SWEEP` です。定点射撃、集中砲火、釘付けはこれには乗らず、艦首を敵へ向けたまま動きます。側面攻撃と背後襲撃も乗らず、智将の翼が敵の側面と背面へ回る動きを続けます。守将は定点射撃を選ぶので、その場から動きません。

智将は中軍を敵の正面に残し、左衛と右衛を側面へ、左翼と右翼を背面へ送ります。敵の分艦隊がこちらに背を向けているときは、中軍以外もそこへ向かいます。

## 陣形を足す

陣形は `src/formations.ts` の `FORMATIONS` に 1 件足します。`src/types.ts` の `FORMATION_IDS` にも同じ id を足します。ここを足さないと型が通りません。

`place` は艦隊のローカル座標を書き込みます。+Y が敵の方向です。関数の最後で重心を原点に戻し、左右の分艦隊へ船を振り分けます。方円だけは中心の中軍を自分で割り当てます。

## 戦術を足す

戦術は `src/tactics.ts` の `TACTICS` に 1 件足します。`TACTIC_IDS` にも同じ id を足します。`step` がその分艦隊の錨を動かします。新しい移動の種類が要るときだけ、共有の `steer` 以外の処理を足します。`sweep` を false にすると、接近しても艦隊の時計回りには乗りません。

## 指揮官を足す

指揮官は `src/commanders.ts` の `COMMANDERS` に 1 件足します。`COMMANDER_IDS` にも同じ id を足します。`base` は戦術ごとの重み、`rules` はその状況で足す重みです。`chooseTactic` が最大の戦術を返します。手動は `auto: false` で、戦術を変えません。

## 艦の性能

戦艦が基準です。巡航艦と駆逐艦は `src/balance.ts` の `CLASS_MODS` で、その倍率から作ります。一つの分艦隊は同じ艦種です。初期の並びは、両翼が駆逐艦、その内側が巡航艦、中軍が戦艦です。開戦前に「分艦隊の艦種と戦術」から隊ごとに変えられます。

艦は艦首の方向へ進み、真横には滑りません。正面の被弾は軽く、背面は重くなります。背面に砲はありません。装甲の数値は被弾倍率で、大きいほど多く削れます。砲の間隔はどの艦種も基準 4.0 秒、斉射ごとに ±10% です。斉射の威力は門数 × 1 門あたりの威力です。

| 艦種 | 耐久 | 装甲（前/横/背） | 速力 | 加速 | 旋回 | 艦首砲 | 舷側砲 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 戦艦 | 54 | 0.50 / 1.00 / 1.50 | 70 | 5.2 | 1.50 | 8 門 × 1.40、280–900、±40° | 16 門 × 0.50、0–420、±50° |
| 巡航艦 | 35 | 0.60 / 1.20 / 1.80 | 89.6 | 7.28 | 2.40 | 6 門 × 1.19、241–774、±40° | 12 門 × 0.425、0–378、±50° |
| 駆逐艦 | 18 | 0.725 / 1.45 / 2.175 | 110.6 | 9.36 | 3.30 | 4 門 × 0.77、146–468、±32° | 12 門 × 0.55、0–344、±58° |

戦艦の斉射は艦首 11.2、舷側 8.0 です。巡航艦は 7.14 と 5.10、駆逐艦は 3.08 と 6.60 です。駆逐艦は舷側の方が重く、戦艦は艦首の方が届きます。画面では戦艦が太く、巡航艦が細く、駆逐艦がさらに細い線です。

遠い相手には艦首を向け、近い相手には舷側を向けます。駆逐艦の分艦隊は戦列の外側に開き、戦艦は中軍に残ります。駆逐艦は最初の被弾で列を抜けると翼が崩れるので、退避で下がるのは戦艦と巡航艦です。

画面上の配置やビームの本数は `FIELD` です。艦の性能ではありません。

## 測定したフレーム時間

この環境は CPU 4 コアで、GPU デバイスはありません。ヘッドレス Chrome で、開戦 1.5 秒後から 2 秒を 5 回測りました。隻数の順は 100、1,000、10,000 を交互に繰り返しています。ページエラーはありません。各回で艦は減っていたので、射撃は動いています。

艦首への旋回を足したあとも、フレームの供給は毎秒 60 回で頭打ちでした。1 万隻の計算と描画は中央値 4.4 ms です。60 fps の枠は 16.7 ms なので、枠の側が上限です。計測は 5 周で、隻数の順は 100、1,000、10,000 です。ページエラーはなく、各回で艦は減っていました。

| 隻数 | フレーム数 | 計算と描画の中央値 | 最小から最大 | 計算 | 描画 |
| --- | --- | --- | --- | --- | --- |
| 100 | 600 | 0.2 ms | 0.0 から 0.4 ms | 0.0 ms | 0.1 ms |
| 1,000 | 600 | 0.6 ms | 0.4 から 1.2 ms | 0.2 ms | 0.3 ms |
| 10,000 | 597 | 4.4 ms | 4.0 から 13.6 ms | 2.1 ms | 2.3 ms |

100 隻の 0.2 ms はタイマーの分解能に近い値です。1 万隻では計算 2.1 ms、描画 2.3 ms です。呼び出し単位のプロファイルは取っていません。この環境に GPU デバイスはありません。
