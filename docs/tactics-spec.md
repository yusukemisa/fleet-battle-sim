# 戦術の仕様

画面上の「戦術」と URL の `blue` / `red` は、その側の動きを選びます。初期値は `r7b` です。`整列` 以外は、1 対 1 で片側 400 隻以上のときだけ分艦隊の動きを上書きします。

選べるものは次です。

| id | 表示 | 内容 |
| --- | --- | --- |
| `r7b` | 槌は列に残す | 開いたときの動きです。翼は中軍と同じ深さから前へ出ません。 |
| `dress` | 整列 | 艦隊の中心と向きを基準に、横に広く浅い等間隔の格子を作ります。前進と回頭は中心が行い、艦は自分のマスへ追従します。前に出た艦は減速し、遅れた艦は少し加速します。敵の射程内では回頭せず、まっすぐ詰めます。正面を向いたまま横へ滑ってマスを守ります。この横滑りは整列のときだけです。射程に入った砲は、敵隊列の手薄な場所か側面を取れる端の、一か所に集まります。沈んだマスは同じ列の後の艦が詰めます。片側の艦隊がいくつでも同じです。 |
| `main` | 以前の動き | 上書きする前の艦隊です。 |
| `table` | 第5回の表 | 指揮官ごとの角度と射程です。 |
| `r7a` | 猛将は戻らない | 第5回の表のまま、猛将は一度離した隊に戻りません。 |
| `r7c` | 守将は900で出す | 第5回の表のまま、守将は 900 で 25 度を出します。 |

`r7b` と `main` は指揮官の頭脳を残します。それ以外はルールの動きになります。`u8`、`u9`、`u10` は選択肢にも URL にもありません。渡しても無視します。`blue=dress` と `blue=整列` は同じです。

同じ側に艦隊が複数あるときは、それぞれの格子を横に連ねて一連の線にし、向きと前進は側で一つにします。翼だけが敵の方へ回頭して列が割れないようにするためです。

整列の間隔は、戦艦の誘爆が隣に届かない 40 を下回りません。2,000 隻を超えると、広い横陣と同じく間隔を艦隊の大きさで開きます（上限は基準間隔の 1.85 倍）。縦は最大 6 列で、横は縦の 4 倍より広くします。接触で両方にダメージが入り、沈んだ艦は周囲を巻き込みます。このダメージは弱めません。初期の艦首間隔は艦隊の横幅と、同じ側の艦隊数で広がります。片側 2,000 隻を超える横陣は、艦の間隔を艦隊の大きさで開き、各隊を横長の浅い塊にします。敵の砲の下では、400 隻以上の艦隊は脅威の方を向いて撃ちます。整列のときは、その向きを艦隊の正面に固定します。
