# 戦術の仕様

画面上の「戦術」と URL の `blue` / `red` は、1 対 1 で片側 400 隻以上のとき、その側の分艦隊の動きを上書きします。初期値は `r7b` です。

選べるものは次です。

| id | 表示 | 内容 |
| --- | --- | --- |
| `r7b` | 槌は列に残す | 開いたときの動きです。翼は中軍と同じ深さから前へ出ません。 |
| `main` | 以前の動き | 上書きする前の艦隊です。 |
| `table` | 第5回の表 | 指揮官ごとの角度と射程です。 |
| `r7a` | 猛将は戻らない | 第5回の表のまま、猛将は一度離した隊に戻りません。 |
| `r7c` | 守将は900で出す | 第5回の表のまま、守将は 900 で 25 度を出します。 |

`r7b` と `main` は指揮官の頭脳を残します。それ以外はルールの動きになります。`u8`、`u9`、`u10` は選択肢にも URL にもありません。渡しても無視します。

接触で両方にダメージが入り、沈んだ艦は周囲を巻き込みます。初期の艦首間隔は艦隊の横幅と、同じ側の艦隊数で広がります。敵の砲の下では、400 隻以上の艦隊は脅威の方を向いて撃ちます。
